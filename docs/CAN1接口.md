# CAN1 BMS 接口

CAN1 连接 6 个 BMS 从控、F405 主控和调试工具，位率为 500 kbit/s。正式接口以 [`Vehicle_Can1.dbc`](../can/Vehicle_Can1.dbc) 为机器可读来源；本文说明报文用途、时序、有效性和工具命令。

## 1. 通用约定

| 项目 | 约定 |
| --- | --- |
| 帧格式 | 经典 CAN 数据帧，不使用 CAN FD 和远程帧 |
| ID 类型 | 本文所有报文均为 29 bit 扩展帧 |
| 数据字节 | Byte0 是数据区第 1 字节 |
| 大端 `uint16` | `value = Byte0 << 8 \| Byte1` |
| 温度 | 原始值减 30 后为摄氏度；`0xFF` 表示无效 |
| 单体电压 | 小端 `uint16`，单位 mV；`0xFFFF` 表示无效 |

接收方按 ID 类型和 DLC 识别报文。周期帧超时后按无效处理；带有效位的测量还必须检查对应有效位。

## 3. 从控采样帧

### 3.1 单体电压

每个从控发送 6 帧，共 23 串：

| 帧号 | 字节 | 内容 |
| ---: | --- | --- |
| 0 | Byte0..1 | 保留 |
| 0 | Byte2..7 | 3 个小端 `uint16` 电压 |
| 1..5 | Byte0..7 | 每帧 4 个小端 `uint16` 电压 |

电压单位为 mV，当前有效范围为 500..5000 mV，`0xFFFF` 表示无效。单体顺序和每个 ID 的字段名见 DBC。

### 3.2 温度

Byte0..7 对应该从控的 8 路温度。物理值为原始值减 30 °C，当前有效原始范围为 0..129，`0xFF` 表示无效。

主控正式固件对每一帧使用 350 ms 超时。一个从控的 6 帧电压和 1 帧温度都在超时内且内容有效时，该从控数据完整。

| --- | --- |
| 0..1 | 包电压，大端 `uint16`，0.1 V |
| 2..3 | 包电流，大端 `int16`，0.1 A；充电为正，放电为负 |
| 4 | SOC，0..100% |
| 5 bit0 | 包电压有效 |

| 5 bit2 | SOC 有效 |

| 6 bit3..0 | 告警等级：0 正常、1 一级故障、2 二级告警 |

Byte5 对应有效位为 0 时，电压、电流、SOC 和极值不作为当前测量使用。

### 4.5 SOP、运行配置和固件身份

`0x186A50F4` 依次发送放电电流、充电/回收电流、放电功率、充电/回收功率上限。四项均为大端 `uint16`，电流单位 0.1 A，功率单位 0.1 kW。CANB 正式 SOP 接口见 [`CANB接口.md`](CANB接口.md)。

`0x186B50F4`：

| 字节 | 内容 |
| --- | --- |
| 0 | 工具协议版本，当前为 4 |
| 1 bit0 | 电流方向：0 正常，1 反转 |
| 1 bit1 | 充电机类型：0 Legacy，1 Chroma |
| 1 bit2 | 固件包含均衡功能 |
| 1 bit3 | 均衡已开启 |
| 1 bit4 | Flash 在线 |
| 1 bit5 | 配置等待保存 |
| 1 bit6 | 电流方向等待保存 |
| 1 bit7 | RTC 有效 |
| 2..3 | 充电机反馈电压，大端，0.1 V |
| 4..5 | 充电机反馈电流，大端，0.1 A |
| 6 | 充电机状态 |
| 7 bit7 | 充电反馈整体有效 |
| 7 bit6..3 | Chroma 电压、电流、保护、输出反馈分别有效 |
| 7 bit2..0 | Chroma 输出状态 |

`0x186C50F4` Byte0 为协议版本；Byte1 bit1..0 为构建类型，bit3..2 为充电机固件变体，bit7 为构建时 Git 工作区有未提交内容；Byte2..7 为大端 48 bit Git 短版本。

`0x186C51F4` Byte0 为协议版本，Byte1 为年份减 2000，Byte2 为月，Byte3 为日，Byte4..7 为 0。

`0x186D50F4`：

| 字节 | 内容 |
| --- | --- |
| 0 | 协议版本，当前为 4 |
| 1 bit7 | IVT 电流在线 |
| 1 bit6 | IVT 电流结果错误 |
| 1 bit5..0 | bit5 U1、bit4 U2、bit3 U3、bit2 As、bit1 W、bit0 Wh 通道状态 |
| 2 | SOC 来源：0 未确定、1 IVT As、2 软件安时积分、3 冻结 |
| 3 | 保留，当前为 0 |
| 4..7 | 电流零偏，大端 `int32`，mA |

`0x187850F4` 为相同 32 项故障的等级表，每项占 2 bit：

```c
level = (data[index / 4] >> ((index % 4) * 2)) & 0x03;
```

0 表示未触发，1 表示一级故障，2 表示二级告警，3 保留。

`0x187750F4` 发送单体过压、欠压阈值和高、低温阈值。电压为大端 mV，温度为“摄氏度加 30”编码。

`0x187F50F4` Byte0..2 为告警开关，Byte3 为格式版本 4。各开关位见 DBC；保留位发送 0。

## 5. 工具命令

### 5.1 统一请求 `0x18A050F5`

所有请求固定 DLC=8。Byte0 高 4 bit 为协议版本 4，低 4 bit 为操作码；Byte1 为 0..255 循环的请求计数；保留字节发送 0。

| 操作码 | 操作 | Byte2..7 |
| ---: | --- | --- |
| `0x01` | 设置充电参数 | Byte2..3 电压，大端 0.1 V；Byte4..5 电流，大端 0.1 A |
| `0x02` | 设置告警阈值 | Byte2..3 过压 mV；Byte4..5 欠压 mV；Byte6 高温编码；Byte7 低温编码 |
| `0x03` | 设置告警开关 | Byte2..4 为 19 个开关位，布局与 `0x187F50F4` Byte0..2 相同 |
| `0x04` | 请求故障复位 | Byte2..4 固定为 `A5 5A 3C` |
| `0x05` | 设置电流方向 | Byte2：0 正常，1 反转 |
| `0x06` | RTC 校时 | 年减 2000、月、日、时、分、秒 |
| `0x0F` | 维护操作 | Byte2 为子操作，Byte3..7 为参数 |

维护子操作：

| 子操作 | 参数 | 返回内容 |
| ---: | --- | --- |
| `0x01` | 无 | 日志数量和 RAM 事件丢弃数 |
| `0x02` | Byte3..4 日志序号，大端 | 一条 16 字节记录，分 4 帧返回 |
| `0x03` | Byte3..5 固定 `C3 3C A5` | 请求清除日志 |
| `0x04` | Byte3：0 Legacy，1 Chroma | 设置充电机类型 |

设置类请求在自检、待机或故障保持状态处理；其他状态返回结果码 2。故障复位只在故障保持状态接受。请求方以应答结果为准，不以 CAN 发送成功作为命令成功。

### 5.2 统一应答 `0x18A650F4`

| 字节 | 内容 |
| --- | --- |
| 0 | 协议版本 4 |
| 1 | 请求计数 |
| 2 | 命令码；维护命令为 `0x80 \| 子操作` |
| 3 | 结果码 |
| 4 | 应答时 BMS 状态 |
| 5 bit0 | Flash 在线 |
| 5 bit1 | 配置等待保存 |
| 5 bit2 | 电流方向等待保存 |
| 5 bit3 | 日志清除中 |
| 5 bit4 | 故障日志等待写入 |
| 5 bit5 | 当前固件允许关闭基础保护 |
| 5 bit7..6 | 保留，当前为 0 |
| 6..7 | 大端命令详情 |

结果码：0 已接受/完成，1 已生效且等待保存，2 状态不允许，3 DLC 错误，4 版本错误，5 参数错误，6 确认码错误，7 Flash 不可用或读取失败，8 日志序号越界，9 日志操作忙，10 日志版本或 CRC 错误。

请求方同时核对 Byte1 请求计数和 Byte2 命令码。结果码 1 表示参数已经生效，保存完成以 `0x186B50F4` 对应待保存位清零为准。

### 5.3 RTC 和日志数据

RTC 应答 `0x18A450F4`：Byte0 为状态，Byte1 为请求计数，Byte2..7 为年减 2000、月、日、时、分、秒。状态 0 成功，1 DLC 错误，3 日期时间非法，4 RTC 未就绪，5 设置失败，6 版本错误，7 请求忙。

日志数据 `0x18A750F4`：Byte0 为版本 4，Byte1 为请求计数，Byte2 为类型。

| 类型 | Byte3..7 |
| ---: | --- |
| 1 | Byte3..4 日志数量，Byte5..6 RAM 事件丢弃数，Byte7 状态位 |
| 2 | Byte3 分片号 0..3，Byte4..7 为记录的连续 4 字节 |

读取记录时按分片号 0、1、2、3 拼成 16 字节，四帧使用同一个请求计数。

## 6. 使用和验证

CAN1 不接 IVT-S `0x512..0x519`；IVT-S 位于 CANB。协议版本变化时，工具先读取 `0x186C50F4` 和 `0x186B50F4`，再按对应版本发送命令。

联调检查 36 帧单体电压和 6 帧温度映射、正负电流编码、有效位、故障格式版本、工具请求与应答配对、日志四分片顺序。
