# 迁移与待确认项

本文件只记录尚未确认的接口和验证。确认完成后，更新正式 DBC、对应接口文档和 `CHANGELOG.md`，并从本文件删除该项。

## CANA、CANB 和 CANC

- 各发送节点负责人确认当前固件与 DBC 一致。
- 用实车或台架原始帧验证 CANB 的 GPS、IMU 和轮胎温度字段。
- 确认遥测 `MotionTelemetry` 与 GPS、IMU 字段的换算一致。

## BMS CAN1 和 CANB

- 由均衡板负责人确认 `0x186450F4..0x186650F4` 的 18 个字节与电芯均衡通道的对应关系。
- 用台架原始帧复核 CAN1 扩展 ID、CANB IVT-S 的 ID 和字节序，以及 Chroma 500 kbit/s、Legacy 250 kbit/s 充电接口。
- 测量 CANB 满载时 SOP 50 ms 帧和 BMS 500 ms 帧的实际周期与丢帧率。
- 确认 ECU 实际使用 `0x4B0..0x4B2` 的字段范围。

## 遥测认证

关闭 MQTT 匿名连接前确认：

- Broker 认证方式和最低 TLS 版本；
- 设备凭据的写入、轮换、吊销和交接方式；
- Topic 读写权限；
- 断线重连、认证失败和时钟异常处理；
- 服务器和 STM32 的上线顺序。

真实地址和凭据不进入本仓库。
